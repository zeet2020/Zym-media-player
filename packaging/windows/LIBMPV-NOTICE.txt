libmpv-2.dll — third-party component
====================================

This folder contains libmpv-2.dll, the mpv media player library, which Zym Player
uses for playback. It is a separate program, distributed here unmodified.

Build used:  shinchiro/mpv-winbuild-cmake, release 20261111
             (mpv-dev-x86_64-20261111-git-bcde6b93cc.7z)
             https://github.com/shinchiro/mpv-winbuild-cmake
mpv source:  https://github.com/mpv-player/mpv  (commit bcde6b93cc)
             This build includes FFmpeg (https://ffmpeg.org) and other libraries
             statically linked by the build recipe above.
